סקירת הפרויקט

🎯 מטרת הקורס

לימוד אנגלית לילדים דרך גיימיפיקציה מלאה – כל שיעור הוא משחק אינטראקטיבי עצמאי. הקורס מספר סיפור של הרפתקה בחלל, ובכל שיעור הילדים מתקדמים בסיפור ולומדים אנגלית בדרך.

👦 קהל יעד

יסודי עד חטיבה (גילאי 7–14). הממשק מותאם לילדים עם מובייל, כפתורים גדולים, ואינטואיטיביות מקסימלית.

🔧 טכנולוגיה נבחרת

  • HTML5 + CSS3 + JavaScript (Vanilla)
  • Web Speech API לזיהוי קול
  • Vimeo embed לסרטוני ABC
  • Vercel לאחסון

🏫 מערכת הקורס

Schooler (סקולר) – מערכת ישראלית לקורסים. כל משחק הוא שיעור עצמאי שמוטמע ב-iframe. המעבר בין שיעורים נשלט דרך מנגנון סיסמה.

3

אינטגרציה עם Schooler

🔐 מנגנון הסיסמה – איך זה עובד?

1

הילד מסיים משחק – המשחק מציג קוד סיום (לדוג׳: KING-2024)

2

ב-Schooler, אחרי המשחק יש בוחן קצר עם שאלה: "מה הקוד שקיבלת?" – הילד מכניס את הקוד

3

אם הקוד נכון → Schooler מאפשרת מעבר לשיעור הבא אוטומטית

4

הסיסמה לכניסה למשחק הבא = הקוד שהתקבל. מניעת דילוג על שיעורים.

⚠️ מגבלה ידועה של Schooler: המערכת לא תומכת ב-SCORM/xAPI. לכן לא ניתן לדווח על completion אוטומטית. מנגנון הסיסמה הוא הפתרון המעשי הטוב ביותר.
💡 אופציה עתידית: אפשר לשלוח window.parent.postMessage({status:"completed"}) מהמשחק – אם Schooler תומכת בו, זה יאפשר completion אוטומטי ללא בוחן. לבדוק עם תמיכה של Schooler.

טכנולוגיית זיהוי קול

✅ המלצה: Web Speech API

  • בנוי בתוך Chrome ו-Edge – ללא עלות
  • אין צורך ב-API key
  • תמיכה ב-iOS Safari (מ-v14.5+)
  • מספיק מדויק לצורך הקורס
  • המשחק עובד ב-HTTPS (Vercel)

🔄 Speechly – אופציה חלופית

  • מדויק יותר לפקודות קוליות
  • יש Free Tier (מוגבל)
  • מצריך API Key ורישום
  • מומלץ אם Web Speech API לא מספיק
